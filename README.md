# URL Shortener API

A lightweight REST API built with **TypeScript** and **Express** that shortens long URLs into 6-character alphanumeric codes, handles HTTP 302 redirects, and tracks link click statistics.

## How to Run

### Prerequisites
* Node.js (v18+)

### Installation & Start
```bash
# Install dependencies
npm install

# Start the server (runs on http://localhost:3000)
npm start

# Run tests
npm test
